# Super Popo World

A meme-filled testing ground for various facets of Super Mario World ROM-hacking, based on a single poorly-drawn image of the pope.

## Quick Setup Guide

**The included file is a delta patch, and requires a copy of the American-region Super Mario World ROM to play.**

1. Download and run [Floating IPS](https://git.disroot.org/Sir_Walrus/Flips/releases?q=v198)
2. Select "Apply Patch"
3. Open `Super Popo World 2.0.2.bps`
4. Select a legally-acquired American-region Super Mario World ROM to apply the patch to
5. Save the patched file as `Super Popo World 2.0.2.smc`
6. Run the resulting ROM in any standard SNES enumlator (for example, [Snes9x](https://www.snes9x.com/downloads.php))

## Features
- Reworked sprites for the main character (Popo), his sidekick (Yobby), his rival (Satae), and his love interest (Gigi)
- Updated text content reflecting the new character identities
- New original music sequences for most levels and maps
- Minor modifications to every level in the game, featuring new collectables
- Integration of community ROM patches from [SMW Central](https://www.smwcentral.net)
- Bespoke bugfixes and features implemented directly in the machine code of the ROM
- A super-secret 97th exit
